# Northwood Cemetery Layout Notes

Based on the photos provided, here is the cemetery layout:

## Streets/Avenues
- **Northwood Ave** - Main avenue
- **Magnolia Ave** - Running through cemetery
- **Dogwood Ave** - Main path
- **Jasmine Ave** - Intersecting avenue
- **Camellia Ave** - Additional path
- **Azalea Ave** - Running through sections

## Section Layout
