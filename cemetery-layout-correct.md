# Northwood Cemetery - Correct Layout

## Orientation
- **North**: N Fodale Ave (top)
- **South**: Toward Leaf Dr (bottom)
- **West**: Mitchell St / Azalea (left)
- **East**: Hibiscus (right)

## Road Layout (Running North-South)
Roads run vertically from Fodale Ave down toward the south:

| Road (West to East) | Between Sections |
|---------------------|------------------|
| Azalea | West border |
| Beech | A and B |
| Chinquapin Ln | B and C |
| Dogwood Ln | C and D |
| Elm | D and E |
| Fig | E and F |
| Gardenia | F and G |
| Heather | G and H |
| Hibiscus | East border |

## Section Layout
Each section is a strip of land BETWEEN two roads:
- Section A: Between Azalea (west) and Beech
- Section B: Between Beech and Chinquapin
- Section C: Between Chinquapin and Dogwood
- Section D: Between Dogwood and Elm
- Section E: Between Elm and Fig
- Section F: Between Fig and Gardenia
- Section G: Between Gardenia and Heather
- Section H: Between Heather and Hibiscus (east)

## Plot Layout Within Each Section
- **Width**: 4 plots wide (2 on west side of center path, 2 on east side)
- **Length**: Rows 1-35 running from North (Fodale) to South
- **Plot positions**: 1, 2, 3, 4 (west to east within each row)

## Plot Numbering
Format: NW-{Section}-{Row}-{Position}
Example: NW-D-015-3 = Section D, Row 15, Position 3
